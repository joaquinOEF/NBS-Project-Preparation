E5 — Necessidades · prontidão · mockup walkthrough · 2026-05-15

The encontro where the project becomes a fundable ask. Three beats: funding breakdown → permit checklist → gap report. By the end, every COUGAR maturity metric (9) and priority flag (6) is set — the BWB handoff content is complete.

Key UX call: R$ amounts are band-based, not exact. Most CBOs don't have line-item quotes at this stage; bands keep momentum without forcing precision the user can't supply honestly.

PermitChecklist · NEW · KB-driven

List rendered from _permits/porto-alegre-map.md (new KB content needed) filtered by bairro + intervention type. Each item: name + department + note + contact + status dropdown + "falou com" field.

GapReport · NEW · CBO view

Auto-generated from all maturity scores + priority flags + missing fields. Three sections: Pontos fortes (green) · Pra fortalecer (amber) · Próximos passos sugeridos (blue).

Each "fortalecer" item maps to a specific concrete action from _gap-recommendations/rubric-to-action.yaml. Each "próximos passos" item is prioritized by impact-vs-effort.

Tone: encouraging, never judgmental. *"Plano de monitoramento (1 → 2)"* — explicit score + actionable next step.
